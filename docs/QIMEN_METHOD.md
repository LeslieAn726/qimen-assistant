# 奇门排盘实现口径

本文描述当前代码的实现边界，便于开发和回归测试；它不是对所有奇门流派的统一定义。

## 数据流

明确的日期时间进入 `lib/qimen.js` 的现有计算流程。节气定局由 `lib/jieduan.js` 及本地历法数据参与，地盘、九星、八门和八神分别由 `lib/dipan.js`、`lib/jiuxing.js`、`lib/bamen.js`、`lib/bashen.js` 计算。页面服务只整理结果，不重新排盘。

## 当前约定

- 使用现有时家奇门转盘实现和原项目既有定局规则。
- 实时排盘入口明确使用 Asia/Shanghai 的当前墙上时间。
- 自定义排盘把用户输入解释为 Asia/Shanghai 的指定日期时间，不做浏览器本地时区二次漂移。
- 今日助手沿用应用已确定的目标日期与参考时间；历史日期由 `?date=YYYY-MM-DD` 驱动。
- 十二时辰边界由项目已有常量与服务处理，子时跨越 23:00–01:00。
- 值符、值使、空亡、马星、暗干、天盘、九星、八门与八神都来自既有计算结果；展示层不补算。

中宫寄宫、天禽等细节严格以当前 `lib/` 实现及其基准测试为准。若调整流派或口径，应新增独立模式并保留旧模式测试，不应在 UI 或 AI 层静默改变结果。

## AI 边界

AI 只能解释系统已经计算完成的盘面和规则分析。不得修改阴阳遁、局数、地盘、天盘、九星、八门、八神、值符、值使、空亡、马星或暗干。
