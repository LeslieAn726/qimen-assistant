# 老黄历模块

老黄历由 `services/almanac-service.js` 调用本地 `lunar-javascript` 生成，不访问黄历 API、网站或爬虫。当前 `package-lock.json` 锁定版本为 1.7.7。

## 输入与时区

服务接收应用已经确定的 `Date`。它不自行做第二次时区转换，也不实现真太阳时。`/today?date=YYYY-MM-DD` 会让黄历与该历史日期同步。

## 输出

当前服务按本地库真实提供的方法整理公历、农历、干支、生肖、节气、宜忌、吉凶神煞、建除十二神、方位、冲煞、胎神、彭祖百忌、纳音、星宿和六曜等字段。字段缺失时返回安全的空值或不展示，不根据经验伪造。

## 离线保证

黄历与奇门是相互独立的确定性模块。网络中断、AI 未启用或 AI Provider 不可用时，黄历仍应正常生成。打包时 `lunar-javascript` 必须作为生产依赖进入应用资源。

## 测试原则

- 使用固定日期验证，避免测试随当前日期漂移。
- 验证结构和库返回能力，不把未经库支持的民俗结论写死。
- 黄历失败应被页面隔离，不影响奇门排盘和每日记录。
